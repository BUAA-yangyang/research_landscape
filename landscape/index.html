Project Research Profile

先校准原点，再绘制地图

版本化证据按“已实现、作者报告、外部验证”分层；冲突材料不静默合并。

表面任务

面对新的大型稀疏线性系统，自动生成一套适合 GPU（图形处理器）的求解配置，并把误差降到工程计算要求的范围内。

技术问题

传统多重网格方法需要专家决定网格层级、层间传递方式、平滑器和许多参数。效果好的顺序算法不容易在 GPU 上并行；容易并行的固定规则又可能在新矩阵上失效。

当前通常怎么解决

主流路线要么手工选择 algebraic multigrid (AMG)（代数多重网格）、不完全分解或近似逆等预条件器，要么让神经网络直接学习近似解。前者稳健但依赖问题和人工调参，后者推理快但高精度、跨来源泛化和失败处置仍较困难。

更底层的研究问题

如何从矩阵本身生成可迁移、可并行、低开销的数值求解组件，同时把高精度正确性和失败处置保留在可验证的经典迭代框架中。

问题 → 核心想法 → 实现方式 → 结果

新矩阵很难人工调参 → 一个约1,500参数的小网络读取每一行矩阵的局部特征 → 网络为多重网格的每一层生成平滑系数 → flexible conjugate gradient (FCG)（灵活共轭梯度法）继续把 residual（残差，即当前答案代回方程后还差多少）压到目标范围；如果学习配置没有达到要求，则尝试传统 Jacobi 配置。性能提升目前仍是作者报告。

公开实现

公开代码包含8个逐行特征、约1,500参数的 RowNet、每行每层4个多项式系数、PyAMG 多重网格层级、块结构识别、FCG 迭代和 Jacobi 备用配置。

作者报告但尚未独立核验

README 和博客报告了 116 个 symmetric positive definite (SPD)（对称正定）矩阵上的通过率，以及 OpenFOAM 流体压力问题上的性能；这些数字目前仍需要独立复现。

Research Evolution

思想之间如何继承、修正与组合

因果边代替简单年表。

  • 修正P01 → P03

    早期方法只能处理规则网格；后续工作改用图网络读取稀疏矩阵，从而能够面对更一般的连接结构。

  • 结合P03 → P04/P11

    神经网络最初只学习粗细层之间怎样传递信息，后来又开始学习粗层节点怎样选择，以及多个层级组件怎样一起设计。

  • 修正P07/P09 → P22/P23

    后续工作发现，减少迭代次数并不自动等于更快，于是开始同时考虑三角求解的顺序依赖、GPU 上的矩阵—向量乘法形式和完整运行时间。

  • 替代端到端神经解 → P13/P14/P18/P24

    神经网络不再独自给出最终答案，而只提供修正量、预条件器或初始解；经典迭代算法继续工作，直到达到要求的精度。

  • 取舍离线学习 → P15/P25

    牺牲生成新算子的表达能力，换取零预训练、可解释反馈与模拟内适应。

  • 继承大模型推理 → P21/Alioth

    保留实例条件化思想，但把部署对象压缩为符号公式或约1.5k参数局部网络。

  • 取舍学习 solver → P20

    现代 GPU 直接求解方法说明，一部分性能问题可以通过重新组织数值计算解决。因此学习方法必须和认真优化过的传统实现比较。

07
Project Positioning

把 Alioth 放回地图

WHERE

位于哪里

Alioth 同时关注四件事：自动生成求解器组件、换到新矩阵后继续使用、由经典迭代保证最终精度，以及让主要计算适合 GPU。它最接近 R1，并使用灵活共轭梯度法完成最后的精确求解。

INHERIT

继承什么

它沿用了平滑聚合代数多重网格、多项式或 Jacobi 平滑、灵活共轭梯度法和残差停止准则，也继承了 P01、P03、P07 所代表的思想：学习一个关键组件，而不是让网络直接给出最终答案。

CHANGE

改变什么

公开 v0 把学习对象放在每一层、每一行的多项式平滑系数上，并用8个无量纲局部特征一次生成这些系数；传统迭代算法仍负责把误差继续压低。

SOLVE

解决什么

它试图同时解决三类困难：固定并行平滑器在新矩阵上可能不稳定，效果好的顺序平滑器难以充分利用 GPU，以及为每个新矩阵重新训练会增加准备成本。目前公开代码证明这种组合已经实现，但还不能证明这些困难都已被解决。

NEW

新在哪里

‘学习平滑器’本身已有 P05/P07；‘由经典迭代继续提高精度’也已有 P09/P14。更可能的新意，是用极小网络根据每一行矩阵的无量纲特征生成平滑系数，并把这种做法用于不同来源的矩阵。

当前最稳妥判断：Alioth 目前更像一种有辨识度的新组合，而不是已经得到充分证实的新范式。它把局部、可并行的组件生成与经典迭代结合起来；若未来能在严格隔离的跨来源矩阵集上胜过认真优化的 GPU 基线，并完整报告所有时间开销和失败情况，这种组合才可能上升为更普遍的方法贡献。
